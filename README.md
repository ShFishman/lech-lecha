# לֶךְ־לְךָ

משחק דפדפן בעברית על **פרשת לך לך** (בראשית י״ב–י״ז): המסע, הרעב ומצרים; המלחמה להצלת לוט; ברית בין הבתרים.

**לשחק:** https://shfishman.github.io/lech-lecha/

*Lech Lecha — a Hebrew browser game about Genesis 12–17. Play it at the link above.*

---

## מה יש כאן

המשחק נפתח בפתיחה קצרה וממשיך בשלושה פרקים ואפילוג. כל הציורים והצלילים נוצרים בזמן אמת בדפדפן — אין קובצי תמונה או שמע, אין ספריות חיצוניות, אין שרת.

**פתיחה — לֶךְ־לְךָ.** חרן עם שחר. הקול: "לֶךְ־לְךָ מֵאַרְצְךָ...". כדי לצאת לדרך צריך לעקור את יתדות האוהל בעצמכם, יתד אחר יתד; כל יתד חושפת שורה על מה שאברם משאיר מאחוריו. רק אחר כך מופיעה הכותרת.

**פרק א — הַמַּסָּע, הָרָעָב, וּמִצְרַיִם.** הליכה בארץ כנען (לחיצה ממושכת כדי ללכת), בניית מזבח באבנים בשכם ובבית־אל, רעב שמוציא את הצבע מן הנוף ומדלל את הצאן, מונה מים ולחם שאי אפשר למלא. בגבול מצרים — "אִמְרִי־נָא אֲחֹתִי אָתְּ": אפשר לנסות לבחור אחרת, והסיפור מסרב בעדינות ("אבל כך לא היה"). שרי נלקחת לבית פרעה; אברם מקבל צאן ובקר וחמורים — וכל מתנה נוחתת כמכה. תפילה שמניבה תחילה שתיקה. הנגעים, "קַח וָלֵךְ", השיבה אל המזבח שבין בית־אל ובין העי, הפרידה מלוט (הבחירה מוצגת מעיניו של לוט) וההבטחה.

**פרק ב — הַמִּלְחָמָה.** משחק של ממש, לא קטע מעבר:
1. *המסע* — מפה מצוירת מחברון עד דן. בוחרים קצב (מתון, מהיר, דהירה) מול כוחם של שלוש מאות ושמונה עשר האנשים; מי שנשחק עד הסוף עוצר לנוח. בשכם הדרך מתפצלת — דרך ההר או דרך הבקעה. אם השחר עולה לפני שהגעתם לדן — הפסדתם, ומנסים שוב.
2. *הלילה* — "וַיֵּחָלֵק עֲלֵיהֶם לַיְלָה": גוררים את הקבוצות סביב מחנה האויב, הרחק מאור המדורות ומן השומרים, ובוחרים את הרגע להכות כשהלפידים דועכים. אם נתגליתם, או אם הכיתור לא שלם — קרב אמיתי: מכים באויב שבתוך המעגל, והודפים את המסתערים בזמן.
3. *הרדיפה והחיפוש* — עד חובה, ואז חיפוש במחנה חשוך עם לפיד אחד שהשמן שלו אוזל: למצוא את לוט, את הנשים והעם, ואת הרכוש.
4. *עמק שווה* — מלכי־צדק, לחם ויין, הברכה; מלך סדום: "תֶּן־לִי הַנֶּפֶשׁ וְהָרְכֻשׁ קַח־לָךְ". כדי להישבע "אִם־מִחוּט וְעַד שְׂרוֹךְ־נַעַל" צריך לאחוז ברכוש — ואז להרפות.

**פרק ג — בְּרִית בֵּין הַבְּתָרִים.** "אַל־תִּירָא אַבְרָם", והתשובה הכנה: "מַה־תִּתֶּן־לִי". מביטים השמיימה (גרירה כלפי מעלה) אל שמי לילה בעומק של כמה שכבות, סופרים כוכבים בנגיעה — והם מתרבים מעבר לכל ספירה. מניחים את הבתרים זה מול זה ואת הציפורים שלמות, ומשיבים את העיט כשהשמש שוקעת. האימה החשכה — נבואת ארבע מאות השנה, שצריך "לשאת" אותה — ואז תנור העשן ולפיד האש העובר בין הגזרים, האור היחיד על המסך. אפילוג קצר: אברם ← אברהם, שרי ← שרה, ברית המילה, ושורה אחת לקורא.

## איך משחקים

- עובד במחשב ובנייד (מגע). מומלץ עם אוזניות.
- לחיצה על המסך מדלגת על השהיות בטקסט; "המשך" מופיע כשצריך.
- ההתקדמות נשמרת במכשיר (localStorage). בתפריט (☰) אפשר לבחור פרק שכבר נפתח, או "התחל מחדש".
- כפתור השתקה בפינה. השמע מתחיל רק אחרי לחיצה ראשונה, כמדיניות הדפדפנים.

## על הטקסט

הפסוקים מובאים על פי נוסח המסורה, עם ניקוד. הנרטיב כתוב בעברית מודרנית. מדרשים (אוּר כשדים, שרי בתיבה, עוג הפליט, אליעזר בגימטריה, מלכי־צדק הוא שם) מסומנים במפורש כמדרש. ה' אינו מצויר לעולם — נוכחותו היא קול, אור וצליל בלבד.

## טכני

- `index.html` יחיד + `css/style.css` + `js/` — ללא בנייה, ללא npm, ללא תלויות. הגופנים (Frank Ruhl Libre, Suez One) נטענים מ־Google Fonts.
- `js/engine.js` — במה, לולאה, פרלקסה (עכבר/מגע/ג'ירו), טקסט, בחירות, לחיצה ממושכת, שמירה. `js/paint.js` — פרימיטיבים ציוריים (שמיים, רכסים, עננים, דמויות, אוהל, מזבח, להבה, ארמון, כוכבים). `js/audio.js` — WebAudio פרוצדורלי (רוח, דרון, עוּד/נאי, תופים, אקורד הברית). `js/scenes.js` — נוף משותף, שיירה, הליכה, מזבח, הקול.
- הפרקים: `js/prologue.js`, `js/ch1.js`, `js/war.js`, `js/ch3.js`.
- לבדיקה אפשר לקפוץ לפרק ולסצנה דרך הכתובת, למשל `?ch=ch2&scene=night&speed=4&unlock=1`.
